# Changelog

## [1.0.8] - 2026-11-14
### Исправлено
- Исправлена сборка Release APK в GitHub Actions при отсутствии файла `debug.keystore.base64` в экспортированном репозитории: добавлена детерминированная генерация ключа подписи на базе секретов репозитория (обеспечивающая единую подпись для всех последующих обновлений приложения без хранения ключей в публичном репозитории), переход на JDK 21 (`actions/setup-java@v5`), автоматическая установка Gradle 9.3.1 и поддержка Node 24.

## [1.0.7] - 2026-11-14
### Изменено
- Настроен автоматический запуск сборки релизного APK, создания GitHub Release (`vX.Y.Z` на основе `versionName`) и отправки уведомления в Telegram сразу при синхронизации ветки `main` из Google AI Studio (без необходимости вручную создавать и отправлять git-теги).

## [1.0.6] - 2026-11-14
### Добавлено и оптимизировано
- Реализовано встроенное автообновление приложения напрямую из GitHub Releases (`sibasyanya/pillbox`) со скачиванием APK внутри приложения, индикатором загрузки и запуском системного установщика через `FileProvider`.
- В графике приема на экране «Сегодня» убрана дублирующая кнопка «Изменить курс» и добавлена кнопка **«Не принято»** для фиксации пропусков приема (с безопасной миграцией базы данных Room `1 -> 2` и сохранением всех данных).
- Во вкладке «Все курсы» на карточку каждого курса добавлена кнопка **«Дублировать курс»** для быстрого копирования схемы фаз в конструктор.
- Выполнена глубокая оптимизация скроллинга `LazyColumn` (облегченные компоненты `FastCard` и `FastActionButton` без теневых слоев и вложенных `Surface`, изоляция подписок `StateFlow` по вкладкам, прямая SQL-агрегация доз и сборка `Release` APK с полной AOT-компиляцией).
- В CI/CD пайплайн GitHub Actions добавлена автоматическая публикация GitHub Release с прикреплением подписанного APK и отправка уведомления о новой версии в Telegram.

## [1.0.5] - 2026-11-07
### Оптимизация производительности и рендеринга
- Вынесены все операции с базой данных SQLite, JSON-резервным копированием и синхронными IPC-вызовами `AlarmManager` / `NotificationManager` из главного UI-потока (`Dispatchers.Main`) в фоновые пулы (`Dispatchers.IO` и `Dispatchers.Default`), что полностью устранило фризы интерфейса при переключении вкладок, сохранении курсов и отметке приемов.
- Сокращен горизонт единовременной регистрации будильников `AlarmManager.setAlarmClock` с 14 до 2 ближайших суток (с автоматическим продлением в `AlarmReceiver`), что уменьшило количество системных Binder IPC-вызовов на 85%.
- Добавлены аннотации `@Immutable` для всех моделей данных и UI-состояний (`MedicationCourse`, `CoursePhase`, `ScheduledIntakeItem`, `CourseBuilderUiState`, `DraftPhaseUiState`), мемоизация (`remember`) вычислений дат, списков и дозировок, а также `contentType` для всех элементов `LazyColumn`.
- Устранен корневой `BoxWithConstraints` (`SubcomposeLayout`) в `MainActivity` и переключена типографика на аппаратно-кэшируемый системный шрифт без накладных расходов синтетической растеризации `.ttf`.

## [1.0.4] - 2026-11-02
### Добавлено и исправлено
- Изменено название приложения на **«Таблетница»** (синхронизировано в `strings.xml`, `metadata.json` и `settings.gradle.kts`).
- Исправлена доставка фоновых пуш-уведомлений: добавлено разрешение `USE_EXACT_ALARM`, переход на приоритетный `AlarmManager.setAlarmClock` (не подверженный задержкам Doze Mode и App Standby в фоне), флаг `FLAG_RECEIVER_FOREGROUND` для мгновенного пробуждения `AlarmReceiver`, а также кнопка теста фонового пуша с задержкой 10 секунд в разделе «Настройки».
- Реализовано полноценное редактирование уже созданных курсов (доступно по кнопке «Редактировать курс» во вкладке «Все курсы» и «Изменить курс» на карточке приема во вкладке «Сегодня») с сохранением всей истории выполненных отметок «Принято» и автоматическим перепланированием будильников.

## [1.0.3] - 2026-11-01
### Исправлено
- Исправлена компоновка карточки «Соблюдение графика» на экране «Сегодня»: текстовый статус выполнения («Выполнено X из Y приемов») вынесен отдельной строкой под заголовком, а справа оставлен компактный бейдж процента без обрезания и наложения элементов.

## [1.0.2] - 2026-11-01
### Изменено и исправлено
- Полностью удалены демонстрационные курсы из начальной инициализации базы данных и конструктора.
- Исправлена верстка верхней шапки экрана «Сегодня»: убраны накладывающиеся векторные элементы часов и креста, панель переключения дат зафиксирована по высоте (`52.dp`), а кнопка «Вернуться к сегодня» вынесена в отдельный полноширинный ряд (`48.dp`) без смещений и обрезания фона.
- Добавлена вкладка **«Настройки»** на нижнюю навигационную панель (рядом с «Сегодня», «Новый курс», «Все курсы»), куда перенесена кнопка отправки тестового уведомления, перепланирование будильников, справочник форм выпуска и резервное копирование.
- Приведены к единой сетке, ширине и высоте (`44.dp` / `48.dp`) все кнопки, чипы выбора форм выпуска, слоты времени, фильтры и кнопки карточек курсов.
- Обеспечена сохранность пользовательских данных на устройстве при установке и обновлении новых версий приложения (отключена деструктивная миграция Room + добавлен экспорт и импорт резервных копий в JSON).

## [1.0.1] - 2026-11-01
### Добавлено
- Реализована архитектура фазового приема препаратов и процедур (`MedicationCourse`, `CoursePhase`, `IntakeRecord`, динамический справочник `MedicationFormEntity`) на базе Room и Kotlin Flow.
- Реализован реактивный калькулятор потребности и длительности курса в реальном времени на экране конструктора («Новый курс»).
- Создан главный экран «Сегодня» с расчетом текущей фазы и дня этапа («Фаза X из Y, день N из M»), отметкой «Принято» в один клик и индикатором соблюдения графика.
- Создан экран «Все курсы / История» с фильтрацией активных и завершенных курсов, досрочным завершением, возобновлением и удалением.
- Настроены точные фоновые уведомления через `AlarmManager.setExactAndAllowWhileIdle`, `AlarmReceiver` (с кнопкой «Принято» в шторке уведомлений) и `BootReceiver` для перепланирования после перезагрузки устройства.
- Добавлен CI/CD пайплайн `.github/workflows/build-apk.yml` для автоматической сборки APK в GitHub Actions.
